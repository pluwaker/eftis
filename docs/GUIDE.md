# Руководство пользователя EFT Personal Assistant

Подробная инструкция по установке, настройке и использованию всех разделов локального дашборда для *Escape from Tarkov*.

---

## 1. Запуск и остановка программы

Приложение работает полностью локально на Python (без сторонних библиотек) и открывается в вашем браузере.

### Запуск без консоли (рекомендуется для Windows)

1. Откройте папку с программой.
2. Дважды нажмите на **`Start EFT Assistant.vbs`** или **`EFT Assistant.pyw`**.
3. Консольное окно не появится — сервер запустится в фоне и автоматически откроет страницу в браузере (по умолчанию `http://127.0.0.1:8745/`).
4. Если сервер уже работает и вы повторно запустите ярлык, программа не создаст дубликат процесса, а просто откроет вкладку с дашбордом.

### Остановка фонового сервера

- Дважды нажмите на **`Stop EFT Assistant.pyw`** — файл отправит команду корректного завершения на локальный сервер и удалит PID-файл.
- Журнал работы фонового режима сохраняется в `eft_assistant.log` в корневой папке проекта.

### Запуск через терминал (опционально)

```powershell
py -3 run.py
```

Дополнительные флаги запуска:
- `--open` — принудительно открыть браузер при старте;
- `--no-browser` — запустить только сервер без автоматического открытия вкладки.

## 2. Настройки и безопасность

Нажмите кнопку **Настройки** в шапке интерфейса, чтобы задать параметры:

- **Режим игры (`PvP` / `PvE`)** — переключает независимые базы прогресса квестов, таймеров и счётчика предметов.
- **Язык интерфейса (`RU` / `EN`)** — мгновенно переводит интерфейс, названия предметов, карт, квестов и загружает гайды на выбранном языке.
- **Чтение логов игры (`watch_logs`)** — фоновый наблюдатель в режиме *Read-Only* читает текстовые `.log`-файлы клиента EFT и автоматически обновляет статусы квестов (принятие, выполнение, провал).
- **Отслеживание скриншотов (`watch_screenshots`)** — отслеживает появление новых скриншотов EFT и по координатам в имени файла отображает вашу позицию на карте.
- **Пути к папкам EFT** — если автоопределение не нашло клиент игры, укажите корневую папку игры или папки с логами и скриншотами вручную.

### Принцип Zero-Touch / Read-Only

Приложение **не** модифицирует файлы игры, **не** читает память процесса, **не** перехватывает сетевой трафик и **не** рисует оверлеи поверх окна DirectX. Оба фоновых наблюдателя можно в любой момент отключить в настройках.

### Оформление и темы

Кнопка **Стили / Тема** в шапке открывает студию оформления, где можно выбрать готовую цветовую схему и настроить акцентные цвета интерфейса под себя.

## 3. Обзор вкладок

### 3.1. Квесты

Центральный экран отслеживания прогресса:

- **Счётчик Kappa** — показывает текущее количество выполненных квестов, необходимых для получения подсумка Kappa.
- **Фильтры** — фильтрация по статусу (`Доступно`, `Выполнено`, `Недоступно`, `Все`), торговцу, карте, принадлежности к Kappa и текстовому поиску.
- **Импорт логов** — кнопка для разового сканирования прошлых локальных логов EFT и восстановления истории выполненных заданий.
- **Смена статуса** — быстрые кнопки на карточке квеста позволяют вручную отметить задание выполненным, активным или сбросить статус.
- **Кнопка «Гайд»** — открывает встроенное окно с подробным руководством по квесту.

#### Пошаговый гайд по квесту

Окно гайда объединяет данные **Tarkov.dev** (брифинг, цели, награды, репутация, открываемые крафты) и подробное прохождение с **Tarkov.Help** (с локальным кешированием текста и изображений):

- В верхней части отображаются ключевые сведения и цели задания.
- В нижней части расположен **пошаговый гайд**: шаги автоматически разбиваются по действиям и скриншотам; переключайтесь между ними кнопками **«Назад» / «Далее»** или кликая по номерам шагов в списке.
- Нажмите на любое изображение в гайде, чтобы открыть его в полноэкранном режиме (лайтбокс).

---

### 3.2. Дерево квестов

Интерактивный граф зависимостей заданий:

- Отображает связи «пререквизит -> следующее задание» с цветовой индикацией статуса.
- Поддерживает масштабирование колесом мыши, перетаскивание полотна и кнопку центрирования.
- Клик по узлу позволяет быстро сменить статус или открыть гайд по выбранному квесту.

---

### 3.3. Карты

Интерактивные векторные SVG-карты локаций:

- **Выбор карты и этажей** — переключение между всеми локациями EFT и их уровнями (подвалы, этажи зданий, лаборатория и т. д.).
- **Слои карты** — включение и отключение маркеров:
  - активных и доступных квестов;
  - выходов ЧВК и Диких;
  - спавнов боссов и вероятностей;
  - закрытых дверей и необходимых ключей;
  - метки позиции игрока (по последнему скриншоту).
- **Всплывающее окно метки (Popover)** — при нажатии на квест или ключ прямо на карте рядом с пином открывается компактная карточка с названием, описанием и отчётливой кнопкой **«Гайд»** для мгновенного перехода к прохождению.

---

### 3.4. Круг Сектантов

Инструмент расчёта жертвоприношений для Убежища:

- **Оптимизатор сборок** — подбирает наиболее дешёвые комбинации предметов (от 1 до 5 слотов) под ключевые пороги Base Value:
  - `350 001+ ₽` — базовый порог;
  - `400 000+ ₽` — порог с шансом 25% на 6-часовой таймер (предметы для квестов и Убежища).
- **Проверка своей корзины** — добавьте любые предметы из поиска, чтобы сразу увидеть суммарную Base Value и ожидаемый тир награды.
- **Таймеры Круга** — запуск и отслеживание обратного отсчёта на **6 ч** и **14 ч** прямо в интерфейсе.

---

### 3.5. Счётчик предметов

Удобный список нужных предметов (для рейдов, Убежища и бартера):

- **Добавление вручную** — через поиск по базе предметов с указанием нужного количества и категории (`Квест`, `Убежище`, `Бартер`, `Другое`).
- **Импорт из активных квестов** — автоматически подтягивает предметы, необходимые для текущих открытых заданий.
- **Быстрый учёт** — кнопки `-1` и `+1` для отметки найденных предметов, фильтр по категориям и очистка полностью собранных позиций.

## 4. Конфигурация и данные

| Файл / Папка | Назначение |
| --- | --- |
| `config.json` | Локальные настройки (создаётся автоматически при первом запуске из шаблона по умолчанию). |
| `eft_assistant.db` | База SQLite с вашим прогрессом квестов, таймерами Круга Сектантов и счётчиком предметов. |
| `cache/` | Локальный кеш JSON-данных `tarkov.dev`, SVG-карт, гайдов и проксированных медиафайлов. |
| `eft_assistant.log` | Лог работы приложения при запуске без консольного окна. |

Чтобы обновить справочные данные (цены Барахолки, новые квесты, правки карт), используйте кнопку **Синхронизация** в шапке или перезапустите приложение.

## 5. Частые вопросы

**Программа не открывается при клике на `.pyw`**
- Запустите `Start EFT Assistant.vbs` — он принудительно вызывает `pyw`/`pythonw` без консоли.
- Убедитесь, что установлен **Python 3.10+** и при установке была отмечена опция *Add Python to PATH*.

**В логах не находятся выполненные квесты**
- Проверьте путь к игре в **Настройках** (`eft_logs_dir`). Обычно это папка `Escape from Tarkov\build` или непосредственно `Logs` внутри неё.
- Убедитесь, что включён переключатель чтения логов, и нажмите **Импорт логов** на вкладке квестов.

**Не загружаются изображения в гайдах**
- Изображения загружаются через встроенный локальный прокси `/api/media-proxy` и кешируются в `cache/media/`. Проверьте доступ в интернет при первом открытии конкретного гайда.
